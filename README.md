### Известное ограничение

Текст без картинки со словом «чек» («мне дали чек, сейчас пришлю») уходит
админу как чек. Фото чека — основной путь, там ложных срабатываний нет.
Решение о сужении эвристики (`looks_like_payment`) — за Ириной.

## Оформление (входная дверь)

1. Оформить самозанятость (ФНС, «Мой налог») — профиль на MAX требует статус.
2. Зарегистрироваться на платформе `business.max.ru/self` с рабочим телефоном;
   имя/фамилия — реальные, как у представителя (без «магазинных» названий).
3. Верифицировать профиль через Госуслуги (для самозанятого других способов
   нет; браузер, разрешить всплывающие окна).
4. Раздел «Чат-боты» → «Создать» → заполнить карточку → дождаться модерации.
5. Токен: «Чат-боты» → (бот) → «Расширенные настройки» → «Настроить».

## Установка (локально)

```bash
cd ai_methodichka_max_bot
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

Создайте `.env` из `.env.example` (MAX_ACCESS_TOKEN, ADMIN_USER_ID, и т.д.):

```
MAX_ACCESS_TOKEN=...
ADMIN_USER_ID=...
WALLET=...
PRICE=1490
PDF_PATH=установка AI агента.pdf
PORT=8000
```

Запуск:

```bash
python bot_max.py
```

## Webhook

MAX присылает события POST-запросами на ваш публичный HTTPS URL. Укажите его в
настройках бота (обычно `https://.../webhook`). Long Polling (`GET /updates`)
есть, но официально «не для production» — потому код рассчитан на webhook.

## Деплой (Render / любой HTTPS-хостинг)

На Render отдельный Web Service из этого репозитория; переменные окружения —
из `.env`. Слушает порт `PORT`.

## Как работает (сценарий)

1. Покупатель начинает диалог → бот шлёт цену и номер кошелька Юмани.
2. Покупатель шлёт скрин-чек → бот уведомляет админа (в MAX) и показывает чек.
3. Админ жмёт «Выдать» → бот загружает PDF через `POST /uploads?type=file`
   и высылает покупателю; «Отклонить» → уведомление покупателю об отказе.

## Механика (по официальной документации)

- Вызовы: `https://platform-api2.max.ru`, заголовок `Authorization: <token>`.
- Отправка: `POST /messages` (`user_id`/`chat_id`, `text`, `attachments`).
- Кнопки: `attachments: [{type: inline_keyboard, payload: {buttons: [...]}}]`,
  нажатие → событие `message_callback`.
- Файл (PDF): `POST /uploads?type=file` → токен →
  `attachments: [{type: file, payload: {token}}]` в `POST /messages`.
- Лимит: ≤2 сообщения/сек в один диалог (в коде — грубая задержка 0,65 с).
